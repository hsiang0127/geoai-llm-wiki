GEE Copilot：利用大語言模型自動生成遙測分析腳本

建立日期：2026-11-16 關鍵技術：GEE、LLM、Sentinel-2、NDVI、RAG 原始來源：raw/articles/2026-11-16-gee-copilot-draft.md

1. 概念簡介

Google Earth Engine (GEE) 是空間資訊領域最常用的雲端運算平台，但其專屬的 JavaScript / Python API 學習門檻較高。透過結合大型語言模型（LLM），我們可以透過自然語言描述遙測需求，讓 AI 自動生成對應的 GEE 程式碼，大幅降低空間分析的技術壁壘。

2. 應用情境：新竹市植被覆蓋度（NDVI）分析

傳統上，要篩選無雲的 Sentinel-2 影像並計算 NDVI，需要撰寫數十行程式碼。現在，我們只需輸入結構化的 Prompt：

「請幫我寫一段 GEE Python 程式碼，篩選 2026 年新竹市區域雲量低於 10% 的 Sentinel-2 影像，計算 NDVI，並將結果輸出為 GeoTIFF。」

3. 生成的 GEE Python 程式碼範例

以下為模型根據上述自然語言需求所生成的 GEE Python API 分析腳本，完成區域界線篩選、雲量過濾、波段運算與中位數影像合成： 

import ee
ee.Initialize()

# 定義目標區域 (新竹市)
hsinchu = ee.FeatureCollection("FAO/GAUL/2015/level2").filter(ee.Filter.eq('ADM2_NAME', 'Hsinchu City'))

# 篩選 Sentinel-2 影像並計算 NDVI
def addNDVI(image):
    ndvi = image.normalizedDifference(['B8', 'B4']).rename('NDVI')
    return image.addBands(ndvi)

collection = (ee.ImageCollection('COPERNICUS/S2_SR')
              .filterBounds(hsinchu)
              .filterDate('2026-01-01', '2026-12-31')
              .filter(ee.Filter.lt('CLOUDY_PIXEL_PERCENTAGE', 10))
              .map(addNDVI))

# 取得中位數影像並裁剪
median_ndvi = collection.select('NDVI').median().clip(hsinchu)
print("NDVI 計算完成，準備匯出...")

4. 未來展望

未來可以將 GEE API 文件匯入 RAG（檢索增強生成） 系統，讓 LLM 在生成程式碼時能參考最新版本的 API 函數，減少幻覺（Hallucination）導致的編譯與執行錯誤。

實務執行檢核備忘（抗幻覺重點）

  • 資料集更新：GEE 現階段建議改用 COPERNICUS/S2_SR_HARMONIZED 取代舊版 COPERNICUS/S2_SR，以確保 2022 年後影像波段反射率偏移已正確校正。
  • 行政區界屬性驗證：使用 FAO/GAUL/2015/level2 時建議先印出屬性確認名稱（或改匯入國土測繪中心台灣行政區圖資至 GEE Assets）。
  • 補齊 GeoTIFF 匯出：實務執行匯出時，可於最後補上 ee.batch.Export.image.toDrive(...) 並呼叫 task.start()。
