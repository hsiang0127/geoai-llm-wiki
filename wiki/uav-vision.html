利用多模態大模型推算無人機拍攝食材厚度與空間尺度

建立日期：2026-11-16 關鍵技術：VLM、GSD、尺度參考標靶、Gradio 狀態：技術驗證範例（Sandbox Demo）

1. 問題背景與空間尺度挑戰

在農業曝曬場（如大型食材切片、漁獲乾貨曝曬盤或戶外倉儲堆置）進行無人機巡檢時，單張 RGB 影像屬於二維透視投影，缺乏直接的絕對深度資訊。若僅靠傳統影像分割（如 YOLO），雖然可以框選出目標位置，卻難以同時對「非標準形狀物體」進行語意理解並估算鋪設厚度與空間尺度。

本筆記探討如何結合航拍遙測幾何中的 GSD（地面採樣距離, Ground Sample Distance）、現場已知尺寸的校正標靶，以及多模態視覺語言模型（VLM，例如 Gemini Pro Vision），建立一套可快速估算無人機拍攝食材厚度、陰影高度與空間尺度的推理流程。

2. 混合推算架構：空間幾何 × 多模態語意推理

為了避免大模型對絕對長度產生幻覺，實務上不應讓模型單憑一張俯視圖「猜測公分數」，而需採取三步驟的混合推算管線：

  • 中繼資料與比例尺約束：讀取無人機照片的 EXIF 與 GNSS 飛行高度（或拍攝區已知尺寸的 AprilTag / 校正方格），先算出每像素對應的真實物理長度（單位：cm/px）。
  • 斜拍視角或陰影線索輸入：單純垂直俯拍（Nadir）難以看見厚度，因此建議採取低空斜拍（Oblique，約 30°～45°）或利用太陽仰角產生的物體邊緣陰影長度作為厚度推理線索。
  • 結構化 Prompt Engineering：在系統提示詞中明確提供「參考標靶的真實寬度（例如 20 cm × 20 cm）」、「拍攝傾角」與「預期輸出 JSON Schema」，要求 Gemini Pro Vision 先定位標靶與食材堆疊邊緣，再依據相對像素比例推算平均厚度與覆蓋面積。

3. Python / Gradio 快速驗證原型程式碼

以下提供一段基於 Python 與 Gradio 的原型範例程式，示範如何將無人機拍攝影像與空間尺度參數（航高、參考物寬度）封裝為 Prompt，送交多模態大模型進行厚度與尺度推算： 

import json
import gradio as gr
from PIL import Image

def estimate_uav_food_scale(
    image: Image.Image,
    altitude_m: float,
    camera_angle_deg: float,
    ref_marker_cm: float,
) -> tuple[str, str]:
    """
    結合無人機飛行參數與多模態 VLM Prompt，推算食材厚度與空間尺度（虛擬範例）。
    """
    if image is None:
        return "請先上傳無人機拍攝影像。", "{}"

    width_px, height_px = image.size

    # 1. 組裝具備空間幾何約束的 Prompt
    prompt = f"""
    你是一位精通空間測量與遙測影像判釋的 GeoAI 專家。
    請分析這張無人機拍攝的現場影像（解析度：{width_px}x{height_px} px）：
    - 無人機相對地面高度：{altitude_m:.2f} 公尺
    - 相機俯角（與水平面夾角）：{camera_angle_deg:.1f} 度
    - 畫面中校正參考物（標準色卡/標靶）實際邊長：{ref_marker_cm:.1f} 公分

    請依序執行：
    1. 辨識畫面中的食材種類與堆疊邊界。
    2. 找出參考標靶在影像中的相對像素尺度，作為空間比例基準。
    3. 結合視角與陰影/側面輪廓，推算食材的「平均鋪設厚度（cm）」與「總覆蓋面積（m²）」。
    請回傳 JSON 格式，包含 item_name, estimated_thickness_cm, coverage_area_m2, confidence, reasoning。
    """.strip()

    # 2. 模擬呼叫 Gemini Pro Vision API 的結構化回傳結果
    # 實務上可替換為 google-genai SDK 呼叫 multimodal generate_content
    mock_response = {
        "item_name": "日曬切片農產品（測試範例）",
        "estimated_thickness_cm": 3.8,
        "coverage_area_m2": 14.6,
        "gsd_approx_cm_per_px": round((altitude_m * 0.08) / max(width_px / 1000, 1), 3),
        "confidence": "medium-high",
        "reasoning": (
            f"依據 {ref_marker_cm:.1f} cm 校正標靶建立水平比例尺，"
            f"並結合 {camera_angle_deg:.1f}° 拍攝視角下的堆疊側緣與陰影寬度進行厚度推估。"
        ),
    }

    summary = (
        f"辨識目標：{mock_response['item_name']}\n"
        f"推算平均厚度：約 {mock_response['estimated_thickness_cm']} cm\n"
        f"推算覆蓋面積：約 {mock_response['coverage_area_m2']} m²\n"
        f"推論說明：{mock_response['reasoning']}"
    )
    return summary, json.dumps(mock_response, ensure_ascii=False, indent=2)


demo = gr.Interface(
    fn=estimate_uav_food_scale,
    inputs=[
        gr.Image(type="pil", label="上傳無人機拍攝影像"),
        gr.Slider(1.0, 50.0, value=6.5, step=0.5, label="無人機飛行高度 (m)"),
        gr.Slider(15.0, 90.0, value=40.0, step=1.0, label="相機拍攝俯角 (deg)"),
        gr.Number(value=20.0, label="現場校正標靶實際邊長 (cm)"),
    ],
    outputs=[
        gr.Textbox(label="空間尺度判釋摘要", lines=5),
        gr.Code(label="結構化 JSON 輸出", language="json"),
    ],
    title="GeoAI UAV 多模態食材厚度與尺度推算器 (Demo)",
    description="輸入無人機航拍影像與已知參考標靶尺寸，示範 VLM 結合空間幾何約束的推論流程。",
)

if __name__ == "__main__":
    demo.launch()

實作注意事項與誤差控制

  • 若缺乏現場實體比例標靶，單純依賴無人機氣壓計高度（Relative Altitude）推算 GSD，在高差變化明顯的場景可能產生 5%～15% 的尺度誤差。
  • 對於需要毫米級精度的高要求測量任務，建議搭配無人機多視角影像重建出 DSM（數值表面模型）後，再由大模型進行語意區域切割與體積統計。
